# Security Policy

## Supported Versions

Only the latest public release of Dayaah Capture receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest public release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

You can report a vulnerability privately using GitHub's
**Report a vulnerability** option under the repository's Security tab.

Alternatively, you may contact the maintainer privately on Discord:

**Discord:** @dayaah
