# Dayaah Capture 2.0.1

Maintenance update for the 2.0 release.

- The capture context menu's **Settings** action now starts a clean replacement
  process in setup mode and terminates the previous process. This guarantees
  that capture, audio, rendering and the residual final frame are closed.
- Ko-fi and GitHub are displayed as full clickable graphic cards instead of
  standard blue hyperlinks.

All Dayaah Capture 2.0.0 features remain included.
